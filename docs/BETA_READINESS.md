## Воспроизведённые проблемы и исправления

| Проблема | Доказательство до исправления | Исправление |
| --- | --- | --- |
| Горизонтальное переполнение на 320 px | Блок этапов выходил до x=355 px; блок заявки — до x=322 px | Одна колонка этапов на узком экране, `minmax(0,1fr)` и размер заголовка |
| Фокус уходил за модальное окно | Браузерный `modal-focus` завершился `Tab escaped modal` | Цикл Tab/Shift+Tab и `inert` для основного содержимого; возврат фокуса |
| Двойной переход в WhatsApp | При `window.open`, возвращающем null, тест зарегистрировал две попытки | Один переход в текущей вкладке; запасной email сохранён |
| Пробелы принимались за модель | Браузер зарегистрировал переход с пустой моделью после trim | Проверка trim, сообщение об ошибке, сброс ошибки при редактировании |
| Сторонний запрос за шрифтом | В сетевом перехвате — `fonts.googleapis.com` | Локальный Manrope WOFF2, 53 776 байт, кириллица и лицензия сохранены |
| Недостаточный контраст части текста | axe: 29 узлов на 375 px, 28 на 1440 px | Затемнены конкретные оттенки подписей и текста; проверка включена в тесты |

Переход из галереи к заявке теперь переводит фокус в поле модели.
Добавлены ссылка пропуска навигации, Escape для мобильного меню и видимый
фокус ползунка. Объяснение формы уточняет передачу текста во внешний сервис;
оно не является политикой обработки персональных данных.

## Повторяемая проверка

```bash
npm ci --ignore-scripts
npx playwright install --with-deps chromium
npm test
```

Статическая проверка охватывает ресурсы и якоря, JSON-LD, sitemap,
отсутствие Google Fonts и состав обеих сборок. Браузерные сценарии:
320/375/768/1440 px, меню, фильтры и все 8 концептов, закрытие галереи,
фокус, ползунок, обязательная модель и однократный переход с кириллицей,
амперсандом и переносами строк. axe запускается на 375/1440 px с закрытой
и открытой галереей. Внешние запросы блокируются; заявки не отправляются.

Последний локальный запуск: **11/11 браузерных сценариев PASS**, статические
проверки PASS. axe-core 4.14.0: 0 автоматических нарушений в четырёх состояниях
(375/1440 px, обычная страница/галерея). В отчётах остаётся категория
`incomplete: color-contrast` для наложений на изображения и отдельных
элементов галереи; её нужно проверить вручную. Полный WCAG-аудит не завершён.

В этой среде штатная загрузка Chromium Playwright вернула повреждённый архив.
Локальная проверка выполнена Playwright 1.62.1 с Chromium из
`@sparticuz/chromium` 153.0.0. В CI используется штатный браузер Playwright;
результат CI следует проверять отдельно. Скриншоты и отчёты axe находятся
в `test-results/` и сохраняются как артефакт CI. Отсутствие нарушений axe
не означает полного соответствия WCAG: ручная проверка со скринридером
остаётся открытой.

## До публичного запуска остаётся

1. Установить точного оператора заявок и реквизиты; проверить модель обработки
   обращений, хостинговых журналов и перехода в WhatsApp. Подготовить документы
   по фактической модели и действующим нормам РФ. Правовая готовность
   в этой работе не подтверждена; фиктивные реквизиты и политика не добавлены.
2. Подтвердить сервер/каталог VEND DESIGN на Beget и российское размещение
   конкретного сервиса; существующий GitHub Pages не считать Beget-хостингом.
3. Сначала разместить закрытую бету по `DEPLOYMENT_BEGET.md`; проверить
   браузер, загрузку ресурсов, HTTPS и журнал ошибок на целевом сервере.
4. Затем согласовать переключение основного домена. Проверить фактические
   A/AAAA, корень/www, сертификат, редиректы и GET всех публичных ресурсов.
5. Проверить приём согласованного обращения вручную, при необходимости
   подключить аналитику и Яндекс Вебмастер / Google Search Console.
   Не объявлять рост конверсии, индексацию или полевые Core Web Vitals
   по результатам локальных тестов.
