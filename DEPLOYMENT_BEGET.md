# VEND DESIGN — перенос на Beget

## Фактическое состояние и цель

Код хранится в GitHub; `main` автоматически публикуется в GitHub Pages.
Выбранное направление для рабочего размещения — российский хостинг Beget.
Этот документ не подтверждает, что перенос уже состоялся. Предыдущие DNS
из `DEPLOYMENT.md` относятся к GitHub Pages, а не к целевому Beget-серверу.

## Сборка беты

Из корня репозитория:

```bash
python3 tests/static_checks.py
python3 scripts/build_public.py --mode beta --output dist/vend-design-beta --zip
```

В архив входят HTML, favicon и assets, включая локальный шрифт с лицензией.
Для беты устанавливается `noindex,nofollow`, sitemap не включается.
Это просьба к поисковым роботам, а не защита доступа. Для закрытой беты
в панели хостинга либо на сервере нужно отдельно настроить авторизацию
и проверить отказ в доступе без пароля. Пароли не помещать в HTML, git или ZIP.
Не принимать реальные данные посетителей до завершения правовой проверки.

Сборщик не включает `.git`, `.github`, `.agents`, тесты, документацию,
инструменты разработки и CNAME. Он отказывается перезаписывать существующий
выходной каталог; для повторной сборки выбрать новый путь.

## Подготовка целевого сервера

1. В панели Beget подтвердить конкретный аккаунт, сервис хостинга, расположение
   сервера и отдельный каталог для VEND DESIGN. Не использовать каталог
   «Пчеловод 63», «Вендинг-Сервис» или другого сайта.
2. Создать/выбрать отдельный адрес беты и привязать только к этому каталогу.
3. Получить точные SSH/SFTP параметры и путь каталога; не угадывать их
   по названию домена. Перед заменой существующих файлов создать резервную копию.
4. Загрузить содержимое собранного каталога, а не весь репозиторий.
5. Настроить сертификат для адреса беты и защиту доступа. Проверить их
   отдельным запросом без авторизации и авторизованным открытием в браузере.
6. Выполнить сценарии из `docs/BETA_READINESS.md` на размещённой бете.

## Основной домен

Переключать после проверки беты и закрытия критических пунктов реестра.
Сохранить текущие DNS-значения для отката. IP брать из панели конкретного
Beget-сервиса. Не подставлять старые IP GitHub Pages. Не менять MX/TXT/NS
и записи других проектов. Проверить конфликтующие A/AAAA и выбранный вариант www.

Для основной версии собрать **production**, затем загрузить её в целевой
каталог после резервного копирования. Этот режим сохраняет canonical,
robots и sitemap основного домена:

```bash
python3 scripts/build_public.py --mode production --output dist/vend-design-release --zip
```

После переключения проверить GET главной, favicon, robots, sitemap,
локального шрифта и всех изображений; сертификат для корня и www;
однократные редиректы HTTP → HTTPS и www → выбранный основной домен;
форму с перехватом перехода. Записать версию выпуска и результат проверки.

Откат: восстановить резервную копию целевого каталога и, если переключалась
зона, сохранённые предыдущие записи только VEND DESIGN. Учитывать, что DNS
может обновляться не мгновенно.

## Что нужно для фактической загрузки

Подтверждённые SSH/SFTP-параметры или доступ к панели и точный отдельный
каталог сайта. В текущей рабочей среде эти параметры не предоставлены.
Перенос и DNS-изменения пока не выполнялись.
