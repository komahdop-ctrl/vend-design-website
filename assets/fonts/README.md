# Manrope

Variable Manrope, weight 200–800, served locally with Cyrillic glyphs retained.

Source: https://github.com/google/fonts/tree/main/ofl/manrope

The upstream `Manrope[wght].ttf` was converted to WOFF2 using fontTools and
Brotli without subsetting. See `OFL.txt` for the SIL Open Font License 1.1.
No request to Google Fonts is needed when visiting this site.
