## Действующая инфраструктура
- Код и изображения: `komahdop-ctrl/vend-design-website` (ветка `main`).
- Бесплатная публикация: GitHub Pages, автоматически по `push` через `.github/workflows/deploy-pages.yml`.
- Технический работающий адрес: https://komahdop-ctrl.github.io/vend-design-website/
- Основной домен: https://vend-design.ru/ (регистратор Beget).
- Файл `CNAME` содержит `vend-design.ru`.
- Эти записи относятся только к `vend-design.ru` и `www.vend-design.ru`; другие домены не менять.

## DNS в панели, обслуживающей домен
В корневой зоне `vend-design.ru` удалить/заменить старые A-записи, ведущие на парковочный IP Beget, и установить четыре A-записи:

| Имя | Тип | Значение |
| --- | --- | --- |
| @ | A | 185.199.108.153 |
| @ | A | 185.199.109.153 |
| @ | A | 185.199.110.153 |
| @ | A | 185.199.111.153 |
| www | CNAME | komahdop-ctrl.github.io. |

Эти значения — рекомендуемые GitHub Pages: https://docs.github.com/en/pages/configuring-a-custom-domain-for-your-github-pages-site/managing-a-custom-domain-for-your-github-pages-site

Перед применением проверить актуальные NS и убедиться, что именно Beget управляет зоной. Не трогать записи MX/TXT, если они нужны для почты. При наличии конфликтующих AAAA-записей для парковки сайта проверить их и удалить/заменить, не меняя NS.

## В GitHub
В Settings → Pages настроить Custom domain = `vend-design.ru`, если ещё не установлен. После обновления DNS убедиться, что проходит проверка DNS и выпускается сертификат. Затем включить `Enforce HTTPS` (когда будет доступно).

## Проверка
- https://vend-design.ru/ возвращает сайт VEND DESIGN, без парковки Beget и предупреждений о сертификате.
- https://www.vend-design.ru/ корректно переходит на основной домен.
- Открываются `/assets/hero.webp`, `/robots.txt` и `/sitemap.xml`.
- Проверить главную страницу, мобильное меню, фотогалерею и создание заявки WhatsApp без фактической отправки.
- После публикации при необходимости зарегистрировать сайт в Яндекс Вебмастер и Google Search Console.
